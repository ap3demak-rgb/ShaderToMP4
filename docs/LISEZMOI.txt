SHADERTOMP4  (voir README.md pour la documentation complete, avec capture d'ecran)
===========
1. Lance bin\ShaderToMP4.exe. Si ffmpeg.exe manque, le programme propose de le telecharger.
2. Glisse tes fichiers shader (.txt / .glsl) dans la fenetre, ou clique "Ajouter...".
3. Regle la video dans "Reglages video", puis clique "Demarrer".
4. Le .mp4 est cree a cote du fichier shader (ou dans le dossier "Sortie").

Glisser des fichiers directement sur le .exe les ajoute et lance le rendu tout de suite.
Boutons : Pause, Annuler, Image PNG, Apercu (+ curseur), Dossier, Profil...
Un rendu long interrompu se reprend en relancant le meme rendu (parties conservees dans <nom>.parts).

Reglages : fenetre -> config.ini ; ou en commentaire dans le shader (prioritaire) :
   // fps=30   // duration=20   // width=3840   // height=2160   // crf=10   // preset=veryslow
   // codec=h265   // container=mkv   // ss=2   // blur=8   // audio=D:\Musique\son.mp3 ...
   (liste complete des cles : README.md)

Compiler : .\scripts\build.bat (Build Tools Visual Studio) ; auto-test : .\scripts\test.bat
